# Amazon India Sales Dashboard

An Excel-based dashboard that analyzes Amazon sales data in India and turns raw sales records into clear, easy-to-read insights.

## Project Overview

This project uses the dataset `Amazon Sales Data India (1).xlsx` to explore sales performance. The dashboard helps answer questions such as:

- Which products and categories sell the most?
- How do sales change over time?
- Which regions or states contribute the most revenue?
